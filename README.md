# Portfolio

Personal portfolio for gui.bertoso: C#, Python, game engines, machine learning and public projects.

Live site: https://gui-bertoso.github.io/portfolio/

## Local preview

No dependencies or build step are needed. From the repository root:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Content is in `index.html`; styling is in `style.css`.

GitHub Pages publishes the site from the repository's main branch. Project links point to public repositories; the private version of Project Horizons is represented by its separately published dialogue addon.
